# 🧮 Calculator  

A **simple yet powerful calculator** built using **HTML, CSS, and JavaScript**. Perform basic arithmetic operations with an intuitive interface.  

## 🔗 Live Demo  
Try the calculator here:  
- **Pages:** [https://akash-calculator.pages.dev/](https://akash-calculator.pages.dev/)  
- **Netlify:** [https://akash-calculation.netlify.app/](https://akash-calculation.netlify.app/)  

## 📌 Features  
✔️ Addition, Subtraction, Multiplication, Division  
✔️ Clear and easy-to-use interface  
✔️ Supports decimal numbers  
✔️ Real-time calculations  

## 🛠️ Technologies Used  
- **HTML** – Structure of the calculator  
- **CSS** – Styling for a clean UI  
- **JavaScript** – Logic and functionality of the calculator  

## 🚀 How to Use  
1. Open the **[Live Demo](https://akash-calculator.pages.dev/)**.  
2. Type in your numbers using the numeric keys (0-9) or the on-screen buttons.  
3. Use the operator buttons (+, -, ×, ÷) to perform calculations.  
4. Press **=** to get the result.  
5. Press **C** to clear the display.
